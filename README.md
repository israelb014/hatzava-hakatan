# הצבא הקטן

משחק קרבות צבא דו־ממדי בעברית, עם אלמנטים קלים של משחק תפקידים. אתם שולטים בגיבור, מגייסים חיילים שנלחמים לבד, ויוצאים למסע של 48 שלבים בארבעה אזורים עד לקרב מול שר השדים.

המשחק חינמי לגמרי: בלי פרסומות, בלי רכישות, בלי אנרגיה ובלי טיימרים. הוא עובד גם בלי אינטרנט.

### הערות התקנה

- **אנדרואיד:** בהתקנה הראשונה צריך לאשר התקנה ממקור לא מוכר. גרסאות חדשות מותקנות מעל הקודמת וההתקדמות נשמרת.
- **חלונות:** הקובץ אינו חתום בתעודה מסחרית, ולכן ייתכן שתופיע אזהרה. לוחצים על "מידע נוסף" ואז "הפעל בכל זאת".
- **לינוקס:** נותנים לקובץ הרשאת הרצה ומפעילים אותו.

## עדכונים אוטומטיים

- **דפדפן:** גרסה חדשה מזוהה ברקע ונטענת במעבר המסך הבא, אף פעם לא באמצע קרב.
- **חלונות ולינוקס:** העדכון יורד ברקע ומותקן בהפעלה הבאה.
- **אנדרואיד:** בפתיחת המשחק מופיעה הודעה "יש גרסה חדשה" עם כפתור "עדכן".

מספר הגרסה מופיע בתחתית כל מסך.

## איך משחקים

- הצבא שלכם יוצא מצד שמאל, השדים מצד ימין, והקרב מתנהל באמצע.
- מזיזים את הגיבור עם החצים שעל המסך. במחשב: מקשי החצים או A ו־D, רווח לתקיפה, 1 עד 3 לכישורים ו־Q לשיקוי.
- שלושה כישורים: סערת חרבות, קריאת קרב וריפוי.
- מנצחים כשכל הגלים הובסו. מפסידים אם הגיבור נופל.
- כוכבים: אחד על ניצחון, שניים אם לגיבור נשארו יותר מחצי מהחיים, שלושה אם בנוסף נפלו לכל היותר רבע מהחיילים.
- חיילים שנפלו צריך לגייס מחדש. אחרי ניצחון חצי מהם חוזרים למחנה, ואחרי הפסד חלק קטן מהם.
- העברת התקדמות בין מכשירים: הגדרות, ואז "קוד גיבוי".

## פיתוח

המשחק כתוב ב־Phaser 3, TypeScript ו־Vite. כל הגרפיקה והצלילים נוצרים בקוד, ואין תלות בשרת או ברשת.

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות לכלכלה, לשמירה ולסימולציית הקרב
npm run balance    # שחקן אוטומטי שעובר את כל 48 השלבים, לבדיקת איזון
npm run build      # בנייה לתיקיית dist
```

כל דחיפה לענף main מעלה את מספר הגרסה, מריצה את הבדיקות, מפרסמת את גרסת הדפדפן ובונה את קובצי ההתקנה לאנדרואיד, לחלונות וללינוקס.

מפתח החתימה של אנדרואיד והסיסמה שלו נמצאים במאגר בכוונה, כדי שכל בנייה תיחתם באותו מפתח.
